# v0.1 POC Validation

PCW-MCP v0.1 is considered a successful functional proof of concept.

The POC validated the core hypothesis:

```text
External durable context and continuity can allow a specialized development workstream to survive finite AI sessions and be reconstructed by different AI clients.
```

## Validated

The following behavior was validated during the POC:

- Local MCP server over stdio.
- MCP Inspector connection.
- Codex consuming PCW through MCP.
- Cursor consuming the same PCW context through MCP.
- Fresh-session reconstruction without previous chat history.
- Client-independent reconstruction across Codex and Cursor.
- `pcw.yml` mapping logical PCW structure independently of physical folder layout.
- Shared context discovery.
- Specialized workstream context discovery.
- Workstreams without specialized context.
- Persistent continuity per workstream.
- Semantic inventory reading.
- Selective inventory search.
- Selective source discovery.
- Markdown/TXT source reading.
- DOCX text extraction.
- PDF text extraction.
- `get_continuity` returning SHA-256 version information.
- `update_continuity` requiring an expected SHA-256.
- Stale continuity writes being rejected.
- Previous continuity content being backed up.
- Atomic continuity replacement.

## Not Yet Fully Validated

The POC validated session independence and interoperability between Codex and Cursor.

It has not yet fully validated true cross-provider interoperability with a clearly different provider stack such as Claude, Gemini, or another non-OpenAI ecosystem.

## Scope

The v0.1 POC is not production-ready. It intentionally avoids cloud services, databases, embeddings, vector search, authentication, and distribution packaging.

The next phase is PCW v0.2 foundation work: documentation, tests, typed configuration, security hardening, and modularization without changing the validated behavior unnecessarily.
